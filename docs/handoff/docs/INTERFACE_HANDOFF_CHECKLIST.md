# Checklist de handoff: Claude Design → Claude Code

## Antes de dar por terminada la interfaz
- [ ] Menú principal y navegación.
- [ ] Preparación de equipo/dificultad.
- [ ] Mapa de expedición.
- [ ] Combate táctico con estado normal.
- [ ] Selección de carta y selección de objetivo.
- [ ] Estados de campeón herido, estrés alto y derribado.
- [ ] Intenciones enemigas y objetivos legales/ilegales.
- [ ] Gear equipado y comparación de objetos.
- [ ] Reliquias y tooltip/explicación de efectos.
- [ ] Descanso, comerciante, evento y recompensa.
- [ ] Resultados de victoria, derrota y retirada.
- [ ] Tokens visuales y componentes reutilizables.
- [ ] Comportamiento de escritorio y ventana estrecha.
- [ ] Placeholders identificados; assets con licencia anotada.

## Artefactos que pasar a Claude Code
- [ ] Archivos de diseño o exportación de Claude Design.
- [ ] Capturas de referencia de cada pantalla y estado importante.
- [ ] Código generado, si existe, con instrucciones de ejecución.
- [ ] Paleta, tipografías, espaciado y tokens.
- [ ] Iconos/assets y su procedencia/licencia.
- [ ] Notas de interacción: selección de carta, objetivo, confirmación, tooltips.
- [ ] Este paquete, especialmente `CLAUDE_CODE_SPEC.md`.

## Al iniciar Claude Code
- [ ] Abrir el repo correcto.
- [ ] Adjuntar/poner los artefactos de diseño en una carpeta `design/`.
- [ ] Pedir auditoría y plan antes de editar.
- [ ] Acordar decisiones bloqueantes.
- [ ] Implementar una fase cada vez y ejecutar tests.
